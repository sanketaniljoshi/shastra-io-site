# Crawler policy — set 23 Aug 2026, made self-sufficient 3 Sep 2026.
#
# This file now states the WHOLE policy on its own. It previously relied on
# Cloudflare's managed robots.txt block, which is injected at the zone edge and
# already disallowed the training crawlers, so they were deliberately not
# repeated here. That was fragile: switching the managed block off would have
# silently allowed every training crawler. Everything is declared explicitly
# below, so the policy is identical whether or not Cloudflare injects anything.
#
# AI SEARCH crawlers are allowed: they produce cited, attributed answers that
# link back here. MODEL TRAINING crawlers are not permitted: that use is
# unattributed, sends no traffic, and cannot be undone once it has happened.
# Providers document the two separately, so this distinction is enforceable.
#
# Google-Extended is ALLOWED here, matching cour.pro, skilyo.com, hridtech.com,
# mpsaerospace.com and kkoob.com. Cloudflare's managed block disallows it and
# cannot be overridden from this file; turn the managed robots.txt setting off
# in the Cloudflare dashboard (Security → Settings → Bot traffic) for this
# line to take effect.

Content-Signal: search=yes,ai-train=no,use=reference
